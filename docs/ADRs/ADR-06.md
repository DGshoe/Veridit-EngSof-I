# ADR 6 ~ Interface web em React
| Status    | DATA |
| -------- | ------- |
| Aceita | 20/10/26 |




## Contexto:
O foco de experiencia do usuario deve ser centrado em fluidez de navegação, por isso, SPAs são as mais ideais.


### Decisão:
Utilizaremos o framework React para o desenvolvimento das paginas do nosso sistema.


### Justificativa
É um framework amplamente utilizado e open-source, além da maioria dos membros do grupo possuirem experiencia com esse framework.




### Consequências
- (+) Componentes reutilizáveis e interface independente dos serviços.
- (−) O front-end tem uma etapa de build separada na implantação.
- (-) Alta chance de lentidão em computadores mais modestos.
